\section{Summary}
Research software engineer at Argonne National Laboratory since 2009. I build scientific software that runs on DOE supercomputers, and lately the tooling that lets AI agents use it. Lead developer of UXarray and its MCP server; contributor to E3SM's SimBoard. Two R\&D 100 Awards.

\section{Experience}
\entryheader
  {Argonne National Laboratory}
  {2009 -- Present}
  {Principal Specialist, Research Software Engineering}
  {Mathematics and Computer Science Division, Lemont, IL}
\begin{itemize}
  \item \textbf{SimBoard (E3SM).} Contribute to the web catalog of E3SM simulation runs: case metadata, provenance, and links to diagnostics. FastAPI, PostgreSQL, React, deployed at NERSC.
  \item \textbf{UXarray.} Lead developer of a Python library for unstructured climate grids, used at DOE labs and NCAR. Made a 300-million-cell, 63\,GB mesh loadable in 306\,s; fixed 0.68\,m of geometric drift with error-free arithmetic; 1.67$\times$ faster in a Numba hot path.
  \item \textbf{UXarray MCP server.} Wrote an MCP server that lets AI agents run UXarray analyses on HPC systems through Globus Compute. Presented at SciFM26 and IEEE eScience 2026.
  \item \textbf{SPOTTER-AI (DOE Genesis Mission).} Attention capture and poisoning experiments on cancer drug-response models, for provenance-based integrity checks.
  \item \textbf{SFNO on Aurora.} Ported a PyTorch climate emulator to Intel GPUs and set up distributed training.
  \item \textbf{CANDLE and IMPROVE.} Built a hyperparameter search workflow that ran 10,000+ training jobs on Summit, Theta, and Cori; led the IMPROVE benchmark framework. R\&D 100 Award, 2023.
  \item \textbf{FLASH-X.} Asynchronous HDF5 checkpointing with compression, cutting checkpoint overhead 40--70\% on Summit. R\&D 100 Award, 2022.
  \item \textbf{MeshKit (PI, DOE NEAMS).} Reactor core mesh generation; a 101-million-element core mesh in about 7 minutes on 712 cores.
  \item \textbf{Maintenance and review.} Maintain the ncvis NetCDF viewer (C++); added the Argo model provider to the E3SM AI platform; regular reviewer on UXarray.
\end{itemize}
